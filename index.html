Compare mode categorises every stretch of OS Open Roads by whether it overlaps OSM's own road network (named roads + OSM's genuinely-unnamed-but-mapped ways) within 20m: fully missing from OSM ("new"), or overlapping for only part of its length ("diverges" — only the non-overlapping stretch is highlighted). OSM's own previously-unnamed clusters are shown separately, split into ones a nearby OS Open Roads match could name ("renamed") and ones neither dataset names ("unknown"). Motorways/slip roads are excluded entirely from the diff — no pedestrian frontage, so any UPRNs a buffer would catch near one aren't real doorsteps.
